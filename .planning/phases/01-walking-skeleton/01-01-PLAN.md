# PLAN 01-01 — Monorepo scaffold + ingest tracer

## Objective

Stand up the monorepo (`apps/web` Next.js + `apps/api` FastAPI + root `docker-compose.yml`), create the unified evidence schema in SQLite, and prove one real end-to-end flow: upload a file in the UI → FastAPI stores it and computes SHA-256 → UI lists it back with its hash. Everything later phases build on this skeleton, so the tracer must be verified working (via Compose) before any expansion task.

### Task 1.2 — Scaffold FastAPI + evidence schema + ingest API
- **read_first:** `phases/01-walking-skeleton/01-CONTEXT.md` (D-03 schema), `.planning/research/STACK.md` (§2, §8)
- **action:**
  1. Create `apps/api/app/` with `main.py` (FastAPI app, CORSMiddleware locked to `http://localhost:3000`, `GET /health` returning `{"status":"ok"}`), `db.py` (sync SQLAlchemy 2.0.x engine, SQLite, `PRAGMA journal_mode=WAL`, `busy_timeout=5000`, session-per-request), `models.py` (`artifacts`: id, source_type, filename, sha256 UNIQUE NOT NULL, ingest_ts UTC ISO, metadata_json; `entities`: id, artifact_id FK, kind, value, span_json).
  2. Create `apps/api/requirements.txt`: `fastapi==0.148.0`, `uvicorn==0.54.0`, `SQLAlchemy==2.0.*`, `python-multipart`.
  3. Implement `POST /api/artifacts` (multipart file + `source_type`): stream-write file to disk, compute SHA-256 during write, insert artifact row, return `{id, sha256, filename, source_type}`. Implement `GET /api/artifacts` (list, newest first) and `GET /api/artifacts/{id}`.
- **verify:** `cd apps/api && pip install -r requirements.txt && uvicorn app.main:app --port 8000 &` then `curl -s localhost:8000/health | grep -q '"status":"ok"'` and upload a fixture: `curl -s -F "file=@/tmp/probe.txt;type=text/plain" -F "source_type=document" localhost:8000/api/artifacts | grep -q '"sha256"'`.
- **acceptance_criteria:**
  - `/health` returns `{"status":"ok"}`.
  - Upload returns a 64-char hex `sha256` and a numeric `id`; `GET /api/artifacts` lists the row; the stored file exists on disk and its on-disk SHA-256 matches the DB value (check with `sha256sum`).

- **action:**
  1. Store uploaded files under `apps/api/storage/<sha256[0:2]>/<sha256[2:4]>/<sha256>` (content-addressed); persist the relative path in `artifacts.metadata_json`.
  2. Assert WAL mode + busy timeout are applied on engine connect (log the pragmas at startup).
- **verify:** Upload two files; `ls apps/api/storage/*/*/` shows hash-prefixed paths; `sqlite3` CLI or a python one-liner confirms `PRAGMA journal_mode;` → `wal`.
- **acceptance_criteria:**

  - `PRAGMA journal_mode` returns `wal` on the app database.
